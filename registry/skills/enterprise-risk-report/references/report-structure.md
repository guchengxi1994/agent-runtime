# 报告写作框架

不要把这个文件当成固定目录模板。

应把它理解为一种写作框架：在保持客户熟悉风格的前提下，让报告能够适应：

- 数据完整度不同
- 指标分布形态不同
- 案例可用性不同
- 报告用途不同
- 主导性发现不同

## 核心原则

报告整体要显得结构清晰、风格专业，但内部章节顺序必须服从证据，而不是服从旧模板。

正式起草前，模型应先回答这些问题：

1. 当前数据最主要的故事线是什么？
2. 哪 2-4 个发现值得获得最多篇幅？
3. 哪些证据强到足以支撑明确判断？
4. 哪些部分因为证据不完整或待执行，只能采用更谨慎的写法？

## 建议写作过程

1. 先识别报告目标。
2. 检查证据包。
3. 选定主叙事主线。
4. 搭建动态提纲。
5. 按“结论 -> 证据 -> 含义”的顺序起草主体段落。
6. 只有在图表真的增强理解时才加图。
7. 最后补上限制、待确认事项和行动建议。

## 可选叙事主线

先确定一个主叙事主线，必要时再补一个辅助主线。

### 1. 趋势驱动型

当最强信号是时间变化时使用。

典型行文顺序：

1. 先概括总体趋势。
2. 解释最关键的拐点或波动阶段。
3. 拆解到底是哪些细分部分推动了变化。
4. 说明这种变化对风险、治理或行动意味着什么。

### 2. 结构驱动型

当最强信号是构成分布、集中度或分层差异时使用。

典型行文顺序：

1. 先说清当前结构长什么样。
2. 再比较主要类别、地区、主体或风险类型。
3. 找出最失衡、最集中的部分。
4. 解释这种结构为什么值得关注。

### 3. 问题诊断型

当任务目标是解释异常结果、可疑模式或成因链条时使用。

典型行文顺序：

1. 明确描述异常或问题。
2. 用证据证明它确实异常。
3. 按证据强弱评估可能原因。
4. 区分已确认原因、较可能原因和仍待确认问题。
5. 最后说明下一步应核查什么、处理什么。

### 4. 治理与行动型

当报告主要面向管理层决策或治理整改时使用。

典型行文顺序：

1. 先指出最核心的治理或风险问题。
2. 再展示其背后的证据。
3. 解释业务影响、法律影响或管理影响。
4. 按优先级、可行性或紧迫性排列建议动作。
5. 标注前提、依赖和待验证事项。

## 柔性章节模块

把这些模块当成积木，不要当成每篇报告都必须一模一样出现的章节。

### 模块 A：标题与定位

交代这份报告是什么、面向谁、用于什么决策或审阅场景。

### 模块 B：执行摘要

尽量写成 1-3 段短段落，而不是一串 bullet。

至少覆盖：

- 最核心的结论
- 最重要的支撑证据
- 最关键的限制或待确认事项

### 模块 C：范围与假设

说明：

- 时间范围
- 数据来源范围
- 组织或地区边界
- 假设条件或缺失数据

如果范围本来就很明确且无争议，这一部分可以缩短。

### 模块 D：核心发现

这通常是报告的中心。

每个主要发现尽量遵循这个结构：

1. 结论
2. 证据
3. 解释
4. 为什么重要

不要堆太多发现。宁可少而强，也不要多而散。

### 模块 E：量化证据

当数字支撑是主体时使用。

可包含：

- 总量
- 趋势
- 交叉分析
- 集中度模式
- 与基线或同期的偏离

不要直接倾倒原始查询结果，要把数字转化为判断。

### 模块 F：案例或样本证据

当代表性案例有助于解释机制、法律模式或经营风险时使用。

使用要求：

- 只选少量代表性案例
- 概括案例模式，不必复述全部事实
- 每个案例都要明确服务于当前段落论点

### 模块 G：图表与解读

图表是支撑证据，不是装饰。

每张图都应回答：

1. 为什么要有这张图？
2. 读者应该从中看到什么？
3. 这张图支撑了什么结论？

如果一张图没有新增理解价值，就不要加。

### 模块 H：建议或行动

当报告需要落到管理动作时使用。

建议的排列方式可以是：

- 按紧迫性
- 按影响大小
- 按可行性
- 按依赖关系

每一条建议都应回扣某个发现，而不是泛泛而谈。

### 模块 I：局限与待确认事项

只要证据不完整、查询待执行或存在推断成分，就应保留这一模块。

要明确写出：

- 哪些查询尚未执行
- 哪些源表或源数据缺失
- 哪些因果判断仍不确定
- 是否存在样本偏差
- 是否有未解决的边界问题

## 行文要求

- 正文以 prose-first 为主，bullet 只能辅助，不能替代主体文本。
- 各章节之间要有明确过渡，让全文像一条完整论证链，而不是碎片堆叠。
- 把“观察到的事实”“推断出的解释”“提出的建议”明确区分开。
- 如果证据弱，就直接承认弱，不要假装结论很稳。
- 如果返回数据的结构与旧客户模板不一致，要保持专业风格，但应根据证据需要重组章节。

## 一个简单的起草规则

如果一时不知道某段怎么写，就按这个顺序组织句子：

1. 发生了什么，或者现在什么是真的？
2. 有什么证据支持这个判断？
3. 这件事为什么重要？
4. 读者应该据此采取什么理解或动作？
